In a previous session we have setup a policy engine for this app and for other workspaces.

The goal of this session is to create a friendly user documentation file that explain the policy management **at a workspace level only**.

- explain how the policy works at workspace level
- give examples for the .nojae/read-write-policy.json
- common gotcha regarding that file

The documents will be decline in two languages:

* POLICY-MANAGEMENT-DOC-EN.md
* POLICY-MANAGEMENT-DOC_FR.md

There will be saved in **docs** folder within the root folder of benchmarkit app.

This document must avoid technical explanation of what is 'under the wood' but only focus on what is needed for the *user* to correctly setup a workspace RW policy.

> Reminder: This is a user documentation only.
